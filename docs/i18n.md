# Workspace 界面语言

前端为 React，原先没有国际化依赖。本次使用统一词典和 React 订阅实现中英文界面，复用 `preferences.ts` 的容错存储接口，不新增运行时依赖。

- 顶部与弹窗提供 `English / 中文` 选择；加载中或本地服务器不可用时仍可切换。
- 首次按浏览器首选语言选择：`zh` 及其地区变体使用中文，英文及其他语言使用英文。
- 用户主动选择保存在 `localStorage` 的 `aw.locale` 中，优先于浏览器语言；存储被禁用时，本次页面内仍可切换。
- 切换时更新页面标题及 HTML `lang`，不重载页面、不重建查询缓存，不改变路由、搜索、表单输入及执行状态。

词典位于 `apps/web/src/locales/en.json`、`zh.json`。静态界面使用有类型约束的 `t(key, values)`；包含名称、计数等变量时使用占位符，禁止将动态用户内容作为翻译键。两个词典的键及占位符必须一致。

`uiMessage` 仅用于应用定义的状态、事件名称、服务状态及已知后端提示。当前 API 的部分提示为英文句子，前端在显示边界匹配明确列出的模板，保留其中的用户名称、路径及诊断原文。后续增加后端提示时应同步增加词条或模板。未知诊断使用本地化的错误标签并保留原文，便于排查。

项目与任务名称、用户上下文、模型 ID、执行指令、模型陈述、JSON 清单、Git diff、代码、命令、文件路径、原始终端输出和会话消息均不翻译。技术缩写、单位和可复制的路径 / 命令示例保留原文。浏览器原生表单校验由浏览器语言控制。

覆盖范围包括侧栏、顶栏、检查面板、概览、项目与任务树 / 依赖图、会话控制台、实验对比 / 命令试验、计算节点与 GPU / 遥测历史、设置、活动、执行总结及外部 Claude 会话面板。

验证命令：

```sh
npm run check
PLAYWRIGHT_EXECUTABLE_PATH=/usr/bin/google-chrome npm run test:e2e
```

`tests/i18n.test.ts` 检查语言判定、词典完整性 / 占位符、动态提示与新增 JSX 文案遗漏。`tests/e2e/i18n.spec.ts` 覆盖浏览器语言、持久化、损坏 / 禁用存储、服务器错误、弹窗切换与输入保留、中英文各主要页面的 1500px / 390px 布局、执行原文保留及中文 Mock 工作流。现有英文任务、实验与导航用例继续运行。

真实付费 Codex / Claude 推理、远程 SSH 节点及真实移动设备 / Safari / Firefox 不属于本次界面验证。外部会话实际文件关联用例需要专用 `CLAUDE_CONFIG_DIR` 与 `WORKSPACE_EXTERNAL_SESSION_E2E=1`，缺少时会跳过；这不影响其面板文案和原文显示测试。
